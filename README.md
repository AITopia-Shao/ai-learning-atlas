# AI Learning Atlas · AI 自学体系

一套从数学、编程和计算机系统通向机器学习、深度学习、强化学习与语言模型的自学路线，配有可离线使用的交互知识图谱和章节学习记录。

图谱包含 **10 个领域、38 门课程/实践模块、147 个可记录章节、123 个独立资料链接**。章节按 0–100 分记录掌握程度，以可修改的预计学时加权；全部子章节完成后，课程和领域才自动点亮。资料链接不重复计分。

## 下载后直接使用

1. 在 GitHub 选择 **Code → Download ZIP**，解压整个文件夹；也可以克隆本仓库。
2. 用 Chrome、Edge 或 Firefox 打开根目录的 **`AI学习图谱.html`**，无需安装依赖或启动服务器。GitHub 文件预览不执行这个页面。
3. 左侧选择章节，输入分数后勾选完成；可修改预计学时。操作详情见 [图谱使用说明](图谱使用说明.md)。

学习记录保存在当前浏览器本机，不随 Git 仓库上传，也不自动跨设备同步。更换浏览器、移动 HTML 或清理浏览器数据前，使用“导出记录”备份，再在新位置导入。外部课程资料需要联网。

## 修改和验证项目

开发工具：**Python 3.10+、Node.js 22+**。构建与测试只使用标准库，不需要 `pip install` 或 `npm install`。以下命令在项目根目录执行：

```sh
python graph/build_graph.py
python scripts/check_project.py
node --test graph/progress.test.cjs
node graph/qa.cjs
```

也可以分别运行 `npm run build`、`npm run check`、`npm test` 和 `npm run test:browser`。浏览器检查需要本机安装 Chromium 系浏览器；脚本检测常用 Chrome/Edge 安装位置，也可用环境变量 `GRAPH_BROWSER` 指定可执行文件。检查会创建隔离的临时浏览器配置和模拟记录，截图与结果写入被 Git 忽略的 `graph/qa-progress/`。

课程结构在构建脚本中人工维护；修改文档、数据或界面源码后重新构建，并一并提交 HTML 和 JSON。不要直接修改生成文件。设计规则见 [graph/DESIGN.md](graph/DESIGN.md)。GitHub Actions 对推送与 PR 执行构建、资料完整性、生成文件一致性、计分和浏览器检查。

```sh

```

该命令只打包已提交文件；学习记录导出、测试输出、日志与本机配置不纳入版本管理。仓库只提供课程资料链接，原站课程内容的权利与使用条款由原作者或学校保留。

## 对原主干的审视

原主干覆盖了数学、编程、传统 AI、机器学习、深度学习和语言模型，但需要调整以下连接。

1. **数学与编程应并行起步。** 18.06 不必等微积分全部学完，CS50P 也不必等数学学完。18.01 的基本微积分完成后，再学 18.02 与连续型概率。
2. **给概率补作业，也给数学补统计与优化。** RES.6-012 是 6.041SC 的配套资源；用前者学习讲解，用后者做题。已有部分统计推断，不需要再完整重学一门概率课；用 MIT 18.05 的统计部分补估计、区间和检验，用 MML 补矩阵求导与优化。[MIT 课程说明](https://ocw.mit.edu/courses/res-6-012-introduction-to-probability-spring-2018/)
3. **Python 语法之后需要桥接。** 补递归、复杂度、队列、堆、图搜索，以及 NumPy、数据处理和训练循环。CS188 的官方先修包含计算机科学与离散数学背景，不能把 CS50P 单独视作全部准备。[Berkeley 课程目录](https://www2.eecs.berkeley.edu/Courses/CS188/)
4. **机器学习入门与理论分开承担任务。** Andrew Ng 建立概念，ISLP 补统计建模与实验，CS229 讲义补推导。无需连续完整修读三套高度重叠的入门课。
5. **D2L 做深度学习主教材，CS231n/CS224n 做专项深化。** D2L 先建立训练与实现能力；视觉、语言和强化学习随后分叉。CS231n 全课不是 CS224n 或 CS336 的硬先修。
6. **强化学习增加完整主线。** 赵世钰负责数学基础，王树森负责深度强化学习扩展，另配编程实验；CS285 留作进阶与作业库。
7. **CS336 是终段的系统性课程。** 中文名称应理解为“从零构建语言模型”。它要求 Python 工程能力、深度学习、PyTorch 和计算系统基础，不能只凭看完 NLP 视频直接进入。现在用 C → CS:APP 核心 → OSTEP/网络按需补充 → 性能实验，落实系统准备；用独立训练器项目落实工程准备。Triton、高性能 attention 和分布式训练的深入实现随课学习。[CS336 先修说明](https://cs336.stanford.edu/spring2025/)

## 推荐结构与先修关系

| 层级 | 必修主线 | 可并行/分支 | 进入下一层的条件 |
|---|---|---|---|
| 基础 A：数学 | 18.01SC → 18.02SC 核心；18.06SC；RES.6-012 + 6.041SC 题目 | 线代与单变量微积分并行 | 会矩阵运算、梯度、条件概率、期望 |
| 基础 B：编程 | CS50P → 程序抽象/递归 → NumPy/pandas/绘图；Missing Semester 核心 | 与数学并行；离散数学与算法按先修衔接 | 独立写函数、数据结构、测试、文件处理、矩阵代码 |
| 系统并行线 | C → CS:APP 核心；OSTEP/网络核心；性能实验 | 基本编程后开始，与 ML/DL 并行 | 理解内存、并发、I/O 与计时；在 CS336 A2 前汇入 |
| 桥接 | 统计推断、矩阵微积分、优化；算法与离散数学基础 | 统计可与 ML 入门交叉 | 能推导并实现线性/逻辑回归 |
| 通识 AI + ML | Andrew Ng 新版专项或 ISLP；CS188；CS229 核心选读 | CS188 搜索部分可先学；概率图模型与 RL 等概率基础完成 | 会建模、验证、误差分析和基本搜索 |
| 深度学习共同基础 | D2L PyTorch：基础、MLP、CNN、序列、注意力、优化 | 用 CS231n 笔记补反向传播 | 能独立写训练/验证/保存/恢复流程 |
| 视觉分支 | CS231n | 目标检测、分割、生成、多模态为深化 | 完成视觉实验并能解释泛化差异 |
| 语言分支 | CS224n 核心 + 独立训练工程 → CS336 | 系统线在 A2 前汇入；RL 策略优化在 A5 前汇入；HF 作工具练习 | G3 工程检查与 G4 性能检查；理解 LM 目标与评估 |
| RL 分支 | 赵世钰 → 王树森 → PPO/SAC 与实践 | 赵前半可提前；深度部分需 D2L 基础 | 能从表格型算法过渡到神经网络策略 |
| 综合输出 | 一个可复现的领域项目；语言方向完成小型 LM 闭环 | 高级研究课按方向选 | 数据、代码、指标、消融、局限均可检查 |

其中“必修”指学习目标对应的主干：想覆盖你列出的全部方向，可以完成三条分支；想先到达 CS336，可以先完成语言分支，视觉专项和高级 RL 不必全部完成。

计算机组成、OS 与计网属于完整 AI 工程体系的基础层，但不要求在开始 ML 前全部修完。本路线要求的是对应阶段的核心能力；完整处理器设计、xv6、TCP 协议栈和深度学习框架实现是方向深化。G1–G4 的具体检查见课程衔接审查。

数学采用稳定的 OCW Scholar 版本。CS188 使用 Spring 2025 归档；CS231n 使用 2025；CS224n 使用 Winter 2025 归档；CS336 使用 Spring 2025 及固定 Git 提交。课程“旧”不等于概念失效，关键是同一作业的说明、数据、依赖、测试属于相同版本。

CS336 的部分默认分支在核验时已变为 2026，因此不要直接下载默认分支再对照 2025 手册。固定链接和提交清单放在语言模型文件及 [版本清单](cs336_2025_versions.json)。
