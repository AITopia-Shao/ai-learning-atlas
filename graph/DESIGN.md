# 图谱与学习记录设计

界面只有左侧目录与全高图谱。移除顶部栏、默认右栏、宣传文本、图上标题、聚焦及专题退出机制。目录内的章节行同时提供完成复选框与分数输入；仅选中章节显示学时编辑和资料按钮。详细资料、解释与帮助按需弹窗，不占据常驻侧栏。设置默认折叠。

## 数据和计分

原始四层内容结构保持：领域 → 课程 → 章节 → 资料。147 个章节标为 `trackable`，具有可编辑 `estimatedHours`。资料和 36 个导航节点标为 `referenceOnly`，不计分、不占权重。资料仍允许多章节引用。

章节记录为 `{completed, score, hours, updatedAt}`，评分范围 [0,100]，学时必须有限且 >0。分数未填与真实 0 分严格区分，完成要求已有分数。输入成绩不自动完成，撤销完成不删除旧成绩与学时。

`progress.js` 是纯规则模块。计算使用学习树的直属子节点，资料引用与先修边不参与递归。只有所有学习子节点完成时母节点才有成绩。母节点总学时为子节点学时之和，成绩按学时加权，递归保持与全部叶子加权等价。中间不舍入，显示至多一位小数。筛选、折叠、选修隐藏不参与计算。

未完成节点和连线为黑灰色。完成后分数映射到 HSL 色相 0–120 度的连续红黄绿光谱。左侧勾/分数、图节点、发出连线和箭头共享同一映射。0 分红色，100 分绿色。父子边反向渲染为子 → 母；先修边保持同级来源 → 后续；可选知识关联和资料引用不作为先修箭头。

课程折叠视图把原始关系投影到可见同级祖先，使用显示起点的真实汇总状态着色，防止一个隐藏子章节完成就点亮整门课的连线。先修关系不再投影到领域层级，避免局部章节依赖被误读成整领域先修或循环依赖；领域总览可通过知识关联开关查看概念联系。点击边仍可查原始关系。层次模式的同列先修边采用分离弧线，避免 A1 → A2/A3/A4/A5 重叠后被误读成 A1 → A2 → A3 的链。

## 保存

记录存放于本机 localStorage `ai-learning-progress-v1`。文件包含 schema、app、granularity 标识，章节 ID 稳定；所有导入数据先验证再预览，用户确认后合并，不匹配 ID 或无效数值拒绝整次导入。改写前读取最新快照，保留另一标签页对不同章节的修改；`storage` 事件同步其他页面。存在未保存内存记录时不以旧快照覆盖。

存储失败不声称保存成功，保留本次页面记录并提示导出。导出为实际 JSON 下载；不写用户源文件、不自动上传、不自动跨设备同步。文件路径/浏览器更换前通过导出和导入迁移。

本机记录无法读取时，导入预览会明确提示替换不可读记录。用户确认有效备份后重试写入；成功才解除存储阻塞并提示已保存。浏览器仍拒绝写入时，只在本次页面合并记录并提示导出，不声称恢复成功。

恢复预览和确认都会重新读取当前存储，即使页面先前处于读取失败状态。若另一页面已恢复有效记录，以该最新快照为基础，只覆盖本页尚未保存的章节修改，再合并导入内容；不把旧页面整份快照覆盖回去。成功保存后清空待保存章节集合。双页面检查同时覆盖恢复、保存失败后的重试、未保存修改的保留及后续导入。

记录字段保存时原位更新目录输入，避免输入分数后立刻点击完成框时，blur 导致 DOM 重建吞掉点击。视图状态保存在 URL fragment，旧版聚焦参数被忽略并清理。成绩不进入 URL，不嵌入生成 HTML。

## 布局和可访问性

原生 SVG 单实例与确定性初始位置。网络力导向稳定后停止；按系统减少动态偏好静态排布。标签碰撞抑制与固定屏幕字号，目录和搜索作为完整替代导航。移动端保留图面和可关闭目录，图面拥有触屏平移/缩放。无第三方 CDN、字体、框架或网络依赖。

## 验证

纯规则测试覆盖真实零分、加权与递归、权重修改、撤销、资料去重、非法输入与导入往返。浏览器检查覆盖完整操作链、原生输入失焦与复选框点击、节点/线条/箭头颜色、层级汇总、持久化、真实导出、导入预览与合并、存储失败、多页面更新、桌面和移动布局。

浏览器测试使用隔离临时配置。`graph/qa-progress` 下的截图与导出文件为模拟记录，仅用于测试；不会写入用户当前浏览器记录。外部课程内容沿用原始核验，没有重新运行课程作业。
