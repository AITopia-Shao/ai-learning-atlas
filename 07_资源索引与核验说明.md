核验日期只说明此次看到的内容，不能保证未来地址、权限或仓库默认分支不变。官方 PDF 文件存在也不意味着相关训练数据和所有外部依赖永久在线。

## 保存资料的建议

每门课保存课程版本、题面、starter code、依赖文件和自己的解答。优先下载当前要学的模块；视频与大数据按需保存。MIT 的 Download Course/Resources 是资源入口，不保证一份小 ZIP 包含所有视频。

对于 GitHub 材料，记录仓库与提交号；遇到默认分支变化，从归档学期或固定提交找回同一套手册与代码。不要通过混合不同年份的答案仓库“补齐”一套实际上不匹配的作业。

数学可在独立解题后使用官方答案纠错；编程课程先用公开测试，再做额外边界检查。作者收录的社区实现仍然是第三方资料，特别是赵世钰仓库中明确标注未经作者逐一验证的代码。
